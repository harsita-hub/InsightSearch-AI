# InsightSearch AI

### AI-Powered Web Search Application

InsightSearch AI is an AI-powered web search application that combines
real-time web search with artificial intelligence to provide
easy-to-understand answers along with relevant web sources.

## Features

- AI-powered web search
- AI-generated answers
- Real-time web information
- Relevant source links
- News search
- Movies search
- Study and education search
- Interesting facts
- Lifestyle information
- Follow-up questions
- Modern dark neon UI
- Responsive web interface

## How It Works

1. User enters a search query.
2. The application searches the web using Tavily.
3. Relevant information is collected from web sources.
4. Groq AI processes the information.
5. AI generates an easy-to-understand answer.
6. Relevant sources are displayed below the answer.

## How to Run

1. Install Python.
2. Install the required dependencies.
3. Add the required API keys in the `.env` file.
4. Run the Flask application.
5. Open the application in a web browser.

## Purpose

The purpose of InsightSearch AI is to make web searching easier and more useful by combining real-time web search with Artificial Intelligence.

Instead of only displaying search results, the application collects relevant information from the web and uses AI to provide clear and easy-to-understand answers along with relevant sources.
